Try a workspace restore

Open two windows on different workspaces in a running Hyprland session. These commands work without a model API key.

  1. In BenX, enter save my work layout.
  2. Move one window to another workspace.
  3. Enter restore my work layout.

BenX matches open windows, moves them back, and reports missing windows or failed moves.

Command reference

Search across compositor, hardware, peripheral, and developer commands.

COMPOSITOR hyprctl dispatch
"switch to workspace 3"

Shifts active viewport to specified workspace on current monitor.

COMPOSITOR hyprctl dispatch
"move this window to workspace 2"

Moves active client address to workspace 2.

COMPOSITOR layout engine
"save current layout as work"

Serializes active client geometry to ~/.benx/layouts/work.json.

HARDWARE powerprofilesctl
"set power profile to power-saver"

Modifies kernel scaling governor across all CPU threads.

HARDWARE upower DBus
"battery status"

Reports percentage, discharge rate, health ratio, and runtime estimate.

HARDWARE nmcli
"scan for wifi networks"

Performs IEEE 802.11 scan and reports active SSIDs and signal strengths.

PERIPHERALS grim + slurp
"screenshot a region"

Interactive bounding box selection copied directly to Wayland clipboard.

PERIPHERALS hyprlock
"lock the screen"

Spawns secure hyprlock PAM authentication session.

DEVELOPER Tesseract OCR
"analyze my screen"

Extracts text and diagnoses errors visible on active display window.

Get started with BenX

The setup script creates a Python environment and starts the terminal UI.

Use Python 3.10+ and run these commands from a Hyprland session for desktop actions.

Clone the assistant

git clone https://github.com/NateshKannaR/BenX-Assisto_V-2.0.git
cd BenX-Assisto_V-2.0

Install dependencies and open the terminal UI

./setup_and_run.sh

You can also activate benx_venv and run python benx.py with the same flags.

Check tools and optional features

./setup_and_run.sh --doctor

Open the plain text prompt

./setup_and_run.sh --cli

Open the local web UI at 127.0.0.1:8000

./setup_and_run.sh --web

Use the system Python for this environment. If you already created an isolated benx_venv, recreate it with system packages enabled before starting GTK.

Install GTK4 bindings on Arch

sudo pacman -S gtk4 libadwaita python-gobject python-cairo

Create the environment with access to the system bindings

python3 -m venv --system-site-packages benx_venv
./setup_and_run.sh --gtk

For AI chat, export GROQ_API_KEY or OPENROUTER_API_KEY before launch. MongoDB storage is opt-in via MONGODB_URI. See the project README for optional system tools.
