Command Reference

Natural Language Command Catalog

Search across compositor, hardware, peripheral, and developer commands.

COMPOSITOR hyprctl dispatch
"switch to workspace 3"

Shifts active viewport to specified workspace on current monitor.

COMPOSITOR hyprctl dispatch
"move this window to workspace 2"

Moves active client address to workspace 2.

COMPOSITOR layout engine
"save current layout as work"

Serializes active client geometry to ~/.benx/layouts/work.json.

HARDWARE powerprofilesctl
"set power profile to power-saver"

Modifies kernel scaling governor across all CPU threads.

HARDWARE upower DBus
"inspect battery telemetry"

Reports percentage, discharge rate, health ratio, and runtime estimate.

HARDWARE nmcli
"scan for wifi networks"

Performs IEEE 802.11 scan and reports active SSIDs and signal strengths.

PERIPHERALS grim + slurp
"capture region to clipboard"

Interactive bounding box selection copied directly to Wayland clipboard.

PERIPHERALS hyprlock
"lock the screen"

Spawns secure hyprlock PAM authentication session.

DEVELOPER Tesseract OCR
"analyze my screen"

Extracts text and diagnoses errors visible on active display window.

Deployment & Installation

Native packages and dependencies for Linux environments.

1. Install System Dependencies
sudo pacman -S gtk4 libadwaita grim slurp cliphist wl-clipboard ydotool networkmanager python
2. Clone & Run Setup Script
git clone https://github.com/NateshKannaR/BenX-Assisto_V-2.0.git && cd BenX-Assisto_V-2.0 && ./setup_and_run.sh
3. Set Free Groq API Key
export GROQ_API_KEY="gsk_your_groq_key_here"
1. Install Dependencies
sudo apt install -y libgtk-4-1 libadwaita-1-0 python3-pip wl-clipboard
2. Clone & Run
git clone https://github.com/NateshKannaR/BenX-Assisto_V-2.0.git && cd BenX-Assisto_V-2.0 && pip install -r requirements.txt
1. Install via DNF
sudo dnf install -y gtk4 libadwaita grim slurp wl-clipboard python3-pip
Launch Terminal TUI Mode
python3 benx_tui.py
Headless Daemon Mode
python3 benx.py --no-gui
